ReturnBy — mobile return desk and refund follow-through

Keep existing purchases at hand on a phone, then follow an expected refund through your own receipt check. Expected amounts, currency, follow-up dates and private notes stay with saved purchases and backups. Ambiguous numeric receipt dates now require an explicit date choice in single and batch review. Refund status is entered by you; ReturnBy does not verify a merchant or bank payment or send automatic notifications.

Requires Python 3. Unzip the browser package, run the included Start ReturnBy.sh (Linux), Start ReturnBy.command (macOS), or Start ReturnBy.cmd (Windows), and open the local address printed by the launcher. Keep the same browser profile and port for existing saved purchases.
