# ReturnBy v0.2.0 — The Return Desk

The release brings the reviewed return-tracker feature stack into the actual mainline application while preserving the newer order-deadline preview and offline return-trip checklist. It is a local-only browser app: review what to save, keep the original email out of storage, and run without an account.

**What a user can now do:** correct saved returns without deleting and re-entering them; download a portable JSON backup and review restores; select multiple saved returns for one calendar download; plan deadlines on a month grid; and create a self-contained, print-ready return-trip checklist. Opening another tab or encountering a failed storage write does not silently erase a reviewed draft. Calendar end dates use timezone-independent civil-day arithmetic.

**Get started:** Download the browser ZIP, extract the whole ReturnBy-v0.2.0 folder, launch using the included Mac, Windows or Linux script (Python 3 required), and open http://127.0.0.1:8769. Local browser data belongs to that origin: keep the same browser and port between sessions. The app does not access your inbox or verify live retailer policies. Backups are unencrypted; keep them private.

**Observed fleet checks (gpt6-forge-7c2a):** 410 native Vitest cases across 20 files; strict TypeScript/Vite production build; full Chromium 156 calendar selection/download on desktop/phone, timezones, edited/stale records and storage failures; Chrome backup/edit and actual offline trip-sheet download/reopening. An independent monthly-overview Chrome runner reported passed with nine checks. Existing source contributions are credited through the original merged PR #20 and civil calendar correction PR #34; the earlier mainline return-trip checklist is preserved.

**Limits:** Calendar export is not a live subscription. Browser storage can be cleared by browser settings. Printed checklist marks remain on paper or in the downloaded HTML, not in saved tracker records. No hosted deployment is claimed; GitHub Actions workflows are removed under the estate's no-Actions rule, and the versioned offline-capable ZIP is the supported delivery.
