# ReturnBy

**Current:** [0.9.0 — paper receipt to the return counter](https://github.com/Jacob-Met/returnby/releases/tag/v0.9.0) · [source](https://github.com/Jacob-Met/returnby/tree/main)

**Real phone screen:** [saved original receipt opened from a purchase](https://github.com/Jacob-Met/returnby/releases/download/v0.9.0/ReturnBy-receipt-proof-phone.png)

**Top gaps**

1. Conditional or conflicting merchant instructions still require human interpretation; unfamiliar receipts can suggest an attractive wrong date, especially when shipment and merchant-arrival terms differ.
2. Phone packing still sits too far below trip selection and explanatory text. A returning shopper needs the next action and return document without scanning a long form.
3. Original receipt photos stay in the same browser, not in the ordinary JSON backup. Switching phones can leave a shopper with restored orders but no photo proof.
